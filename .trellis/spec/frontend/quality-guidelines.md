# Quality Guidelines

## Tooling Contract

- Use pnpm; `preinstall` rejects other package managers.
- Biome owns TypeScript/Astro/Svelte formatting and linting. The repository uses
  tabs and double quotes. Do not mass-format unrelated files.
- `pnpm check` runs Astro diagnostics.
- `pnpm type-check` runs TypeScript with `--noEmit --isolatedDeclarations`.
- `pnpm build` is the rendering integration gate: LQIP generation, Astro build,
  font subsetting, and Pagefind indexing.

CI currently runs Astro check and build on Node 22/23 plus a Biome job. There is
no dedicated unit-test framework, so successful compilation is not a substitute
for visual and interaction review.

## Required Checks

- Content/config/assets: `pnpm check` and `pnpm build`.
- TypeScript or component logic: add `pnpm type-check`.
- Interactive or visual work: inspect with `pnpm dev` or `pnpm preview` at
  relevant desktop and mobile widths.
- Navigation changes: exercise a second Swup navigation, not only first load.

## Generated Files

- `src/constants/lqips.json` is generated and committed; review changes from
  `pnpm lqips`/`pnpm build`.
- `src/constants/icons-data.json` is committed but is not generated by the
  current build script.
- `dist/` is build output and must not be committed unless a separate release
  workflow explicitly requires it.

## Review Checklist

- No demo identity, stale domain, or external service credential remains in
  personalized configuration.
- Content conforms to `src/content.config.ts`; production drafts stay hidden.
- Local image paths use the correct `src/assets` versus `public` convention.
- Interactive controls are keyboard-accessible and survive Swup navigation.
- Feature flags, navigation links, sidebar entries, and sitemap behavior remain
  consistent.
- No unrelated formatting, generated asset, or lockfile churn is included.

## Avoid

- Do not commit secrets, tokens, analytics credentials that are meant to be
  private, or private user exports.
- Do not accept `pnpm build` alone as proof of human visual quality.
- Do not edit generated files by hand when a repository script owns them.
- Do not use `pnpm lint` casually on a dirty tree: it writes safe fixes across
  `src`; scope and review its changes.

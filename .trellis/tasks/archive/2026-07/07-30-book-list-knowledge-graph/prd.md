# 书单与书籍知识图谱

## Goal

在现有 Firefly 网站中增加可浏览、可筛选的个人书单，并让访客进入单本书页面后能够查看和探索该书的知识图谱。首版以“想读书单 + 预读知识地图”呈现阅读计划，用户阅读后可逐步沉淀为正式读书笔记与知识图谱。

## User Value

- 访客可以快速了解站长的阅读计划、预读关注点和知识探索方向。
- 访客可以从一本书的核心概念出发，探索概念、章节、人物或方法之间的关系。
- 站长能够使用适合静态站点和 Git 工作流的方式持续维护书籍与图谱内容。

## Confirmed Facts

- Firefly 是 Astro 7 静态优先站点，使用 Svelte 5 交互岛，不依赖运行时数据库。
- 内容由 `src/content.config.ts` 中的 Astro Content Collections 在构建时校验和加载。
- 站点已有 Markdown/MDX、Pagefind 搜索、Wiki Link、Mermaid/PlantUML 和图表缩放/全屏能力。
- 页面使用 Swup 做局部导航；新增交互组件必须正确处理挂载、卸载和返回导航。
- 站点同时支持根路径与 GitHub Pages 子路径部署；新增内部 URL 和资源必须遵守 `url()`/Astro base 约束。
- 当前导航没有书单入口，也没有书籍内容集合或知识图谱领域模型。
- 仓库保留了已停用的 Bangumi 书籍组件和公开 API 配置，但没有公开路由；当前
  账户仅有 3 条书籍类记录，且偏漫画/轻小说，因此不适合作为知识书单的主要
  内容源。现有状态文案、筛选和卡片模式仍可选择性复用。
- 用户在 `/home/yuanzhi/下载` 中提供了 15 个 EPUB 文件，对应 14 本独立书
  （《金钱心理学》的两个文件内容哈希一致）。EPUB 内置元数据可提供书名、
  作者、语言和部分 ISBN，目录可辅助建立章节锚点与候选概念。

## Requirements

- 提供一个独立书单入口和静态可索引的书单页面。
- 书单至少展示书名、作者、封面、阅读状态、主题标签和预读关注点。
- 访客可以按关键词、阅读状态和主题筛选，并可清除全部筛选。
- 每本书拥有稳定、可分享、可被搜索引擎索引的详情 URL。
- 单本书详情页同时承载书籍元数据、预读说明、可逐步补充的阅读笔记和知识图谱。
- 图谱必须标明“预读知识地图”或“正式知识图谱”状态，不得把 AI 整理结果
  冒充为用户读后观点。
- 首版采用“可探索图谱”，而不是只读关系图或跨书知识应用。
- 知识图谱支持节点与关系的可视化、缩放/拖拽、节点选择、邻居高亮、
  按节点/关系类型筛选及文字详情查看。
- 图谱节点存在笔记锚点时，可以跳转到详情页对应章节。
- 单书图谱默认先提供按核心主题、章节/主题分区和关键概念组织的结构概览，
  再允许进入完整关系探索；不能要求访客先理解一张一次性铺满的关系网。
- 对已经整理整书结构的图谱，默认概览必须显示按原书顺序组织的全书主线：
  核心问题、全书主张、各部分的论述角色、认知推进、部分间交接与全书落点；
  概念关系网作为辅助探索层，不能替代作者的论述顺序。
- 节点与关系必须区分“来源内容的重新表述”“编辑整理推断”和“个人笔记”，
  并在存在来源位置时允许访客查看对应章节或定位信息。
- 公开页面以重新组织的短总结为主要阅读内容；原文只允许作为带出处的短摘录
  按需展开，不展示完整章节或可替代原书的连续内容。
- 图谱不能成为阅读内容的唯一入口；移动端、键盘操作或脚本失效时仍需有可读的文本替代。
- 书籍和图谱数据在构建期进行类型与引用完整性校验，避免悬空边、重复 ID 或缺失必填字段上线。
- 首版优先保持静态架构，不引入数据库、登录、在线编辑器或服务端图数据库。
- 新页面和资源兼容亮/暗主题、Swup 导航、根域部署与子路径部署。
- 书单首页和单书详情使用书籍目录型左侧栏，不显示通用头像、文章分类和标签；
  单书详情还应提供本页主要区块和章节锚点。
- 书单分类与主题标签必须表达不同层级：分类用于稳定的目录分组，主题标签用于
  多选的细粒度内容描述；阅读状态作为独立筛选维度。
- 左侧目录是稳定导航，不随关键词、阅读状态或主题筛选隐藏书籍；搜索、分类、
  阅读状态和主题筛选统一由书单主区域管理，并可通过 URL 恢复、分享及浏览器
  前进/后退。

## Acceptance Criteria

- [x] 导航中存在书单入口，书单页在桌面和移动端均可浏览。
- [x] 书单内容来自一个具有构建期 schema 校验的独立内容源。
- [x] 书单至少支持关键词、状态和主题中的两类筛选，并提供无结果状态。
- [x] 每本已发布书籍可通过稳定 URL 进入详情页，草稿不出现在生产构建中。
- [x] 首版 5 本书均显示为“想读”，不展示个人评分或读后评价。
- [x] 每本书可以定义自己的图谱节点与带类型关系，非法节点引用会使检查或构建失败。
- [x] 图谱页面明确显示“预读知识地图”、内容依据和 AI 辅助状态。
- [x] 图谱支持平移、缩放、节点选择、关系辨识和一键恢复视图。
- [x] 选中节点后可阅读节点说明，并可定位到相关章节或笔记内容（存在关联时）。
- [x] 没有 JavaScript 或无法操作画布时，页面仍提供图谱摘要或结构化关系列表。
- [x] 单书图谱默认展示渐进式结构概览，并可切换到完整关系探索和结构列表。
- [x] 《爱的艺术》提供首个“全书主线”样板，覆盖问题、理论、社会诊断、
  实践和结论，并允许逐段展开关联概念与内容依据。
- [x] 节点详情显示总结、内容性质和来源位置；可选原文摘录保持简短且不默认展开。
- [x] 关系详情能够区分来源内容与编辑整理推断，不把推断关系呈现为作者明确结论。
- [x] 图谱在窄屏上不产生页面横向溢出，并提供触控友好的控制方式。
- [x] 页面经过 Swup 前进、返回和重复进入后不会重复挂载监听器或丢失交互。
- [x] 书单与详情页拥有合理的标题、描述及书籍结构化数据。
- [x] `pnpm check`、`pnpm type-check` 和 `pnpm build` 通过。
- [x] 书单首页左栏显示书籍目录，单书详情左栏同时显示书籍目录和本页目录。
- [x] 从普通页面、书单、单书详情之间经过 Swup 导航时，通用侧栏与书籍目录正确切换。
- [x] 左侧目录按主分类显示书籍数量，分类可展开，并始终保留全部书籍导航。
- [x] 分类、阅读状态、主题和关键词筛选使用统一 URL 状态，刷新及浏览器前进/后退后结果一致。
- [x] 主区域集中提供分类筛选、结果数量、当前筛选和清除入口；左侧目录仅对
  当前分类做轻量提示，不复制筛选控件。

## Out of Scope for MVP

- 用户账户、收藏、评分或阅读进度同步。
- 浏览器内编辑书单或图谱。
- 运行时图数据库、全文语义检索或聊天问答。
- 未经人工复核就直接发布 AI 自动提取的知识图谱。
- 跨全部书籍的全站统一知识网络、跨书关系和语义搜索；可作为后续阶段。

## Decisions

- 图谱体验：选择可探索图谱。首版包含节点选择、邻居高亮、类型筛选、详情面板
  和笔记章节跳转；不做全站跨书图谱。
- 内容维护：选择仓库内的结构化数据。每本书使用 Markdown/MDX 承载元数据与
  阅读笔记，并使用相邻 JSON/YAML 文件定义图谱节点和关系。
- AI 可以根据合法持有的目录、EPUB 内容或读书笔记生成候选节点和关系，但
  必须公开标明 AI 辅助状态与内容依据；正式知识图谱仍需用户阅读和校对。
- EPUB 仅作为本地规划和内容整理输入；原始 EPUB、完整章节、长篇原文摘录及
  其他可替代原书的内容不得复制到网站仓库或公开构建产物。
- 用户确认允许从选定 EPUB 中提取内置封面用于个人网站展示。实现时只保留
  压缩后的低分辨率 WebP 衍生图，不复制原始 EPUB；封面必须有书名形式的
  替代文本，并通过 Astro 资源管线处理。
- 首版内容规模为 3–5 本精选书。至少 1 本具有较完整、可覆盖全部图谱交互的
  知识图谱，其余书籍允许使用较小但真实的图谱。
- 首版确定使用以下 5 本本地 EPUB：
  - 《思考，快与慢》：完整图谱样本；
  - 《金钱心理学》：中型图谱；
  - 《被讨厌的勇气》：中型图谱及章节跳转样本；
  - 《纳瓦尔宝典》：小型图谱；
  - 《爱的艺术》：小型图谱。
- 以上 5 本书当前均为“想读”。首版不得展示个人评分、读后评价或声称这些
  图谱来自用户的阅读总结。
- 预读图谱采用混合深度：
  - 《思考，快与慢》允许基于 EPUB 正文生成较完整的概念候选图谱，并明确
    标注为“AI 辅助整理的预读知识地图”；
  - 其余 4 本只依据 EPUB 元数据、目录和简介制作较小的预读图谱；
  - 用户阅读后，可将图谱来源逐步替换为个人读书笔记并升级为正式知识图谱。
- 单书详情采用同一份图谱数据驱动三种阅读方式：
  - “结构概览”默认按章节/主题分组，只先展示高重要度节点，其余节点按组展开；
  - “关系探索”保留完整网络、节点/关系筛选和一阶邻居高亮；
  - “结构列表”提供完整、可索引和无画布依赖的文本入口。
- 内容呈现遵循“总结为主、原文为证、个人观点单独呈现”：
  - 节点总结使用重新组织的短文本；
  - 来源位置和可选短摘录用于复核，不默认发布或展开原文；
  - AI 或编辑者根据目录、主题作出的关系判断标记为“整理推断”；
  - 只有阅读后的个人记录才标记为“个人笔记”。
- 整书主线与概念网络是同一图谱的两个互补层次：
  - 主线保留原书目录顺序和各部分之间的论述交接；
  - 概念网络用于跨章节探索，不从相似度或关系密度反推作者主线；
  - 目录层面的主线整理统一标记为“整理推断”，不得冒充正文明确论证。
- 思维导图编辑/生成工具在首阶段属于 Firefly 仓库内的本地开发工具，直接读写
  `src/content/books/<slug>/graph.json`，不作为线上公开编辑器，也不通过单独
  服务运行。只有出现多项目复用、独立发布或多人协作需求时才拆分仓库。
- 用户确认每本书只能属于一个稳定主分类，并可同时拥有多个主题标签。首批分类
  为“认知与决策”“财富与成长”“心理与关系”。

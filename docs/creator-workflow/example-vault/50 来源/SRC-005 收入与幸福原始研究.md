# 收入与幸福原始研究

作者：Matthew A. Killingsworth、Daniel Kahneman、Barbara Mellers。标题：Income and emotional well-being: A conflict resolved。DOI：10.1073/pnas.2208661120。

[论文原页](https://www.pnas.org/doi/10.1073/pnas.2208661120)已读取摘要、结果和样本说明。重新分析发现，收入与情绪幸福感的关系在不同群体间有差异，不能概括为所有人达到某个收入后都不再更幸福。

核查范围：读过论文相关文本；没有下载数据重新计算，也没有完成全部后续争议的文献综述。样本为美国就业成年人，横截面关联不等于提高收入的因果效果。

反驳对象是“统一幸福收入上限”的泛化，并不反驳“知足有价值”，更不能推出“收入越高所有人必然更幸福”。用于 [[20 知识卡片/FI-004 幸福不能套用统一收入上限]]。

# CFPB 财务福祉框架

[机构原文](https://www.consumerfinance.gov/consumer-tools/educator-tools/financial-well-being-resources/explore-findings/)已读取，页面显示最后更新为 2024-12-12。

支持的局部判断：讨论财务状况时，可以同时考察日常控制、应对冲击、目标进展与选择权。

边界：财务福祉是该机构的概念；不能据此宣布它给出了统一的“财富自由”定义，不能把其美国研究直接当作中国家庭标准。

对应 [[20 知识卡片/FI-001 财富自由的工作定义]]。

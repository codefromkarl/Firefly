# 纳瓦尔的工作与退休

书籍：[[10 书籍/the-almanack-of-naval-ravikant|纳瓦尔宝典]]。

[编者公开章节](https://www.navalmanack.com/almanack-of-naval-ravikant/find-work-that-feels-like-play)已实际读取。作者采用宽泛的退休观，把收入覆盖生活、减少需求和喜欢所做之事放在同一讨论中。

材料类型：编者整理的个人观点，不是适用于所有家庭的财务测量标准。

我的边界判断：工作令人满足，与停止工作后仍可支付生活费用，需要分别判断。用于 [[20 知识卡片/FI-003 喜欢工作与经济独立是不同问题]]。

# 财富自由的工作定义

在明确生活方式、家庭责任和时间范围后，不再依赖持续劳动收入也能维持生活，并留出应对变化的空间，工作因此成为更可选择的事。

这是本期提出的工作定义。来源支持其中的时间自主、容错、多维观察；没有任何一个来源直接给出这句完整定义。

边界：没有承诺永久安全，没有给出统一资产门槛或固定收益率；需要为具体家庭另行分析。不能把心理满足替代基本费用。

文章用途：定义段。待作者确认措辞与价值取向。

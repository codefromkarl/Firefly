# 幸福不能套用统一收入上限

不采用“所有人超过某一收入后，钱就毫无意义”作为支持知足的论据。已读原始研究呈现群体差异与关联，不能直接算出个人财富自由门槛。

边界：美国就业成年人样本，不等同中国家庭；相关不等于因果；本轮未复现数据。反例限制主张范围，不保证相反主张成立。

文章用途：反例段。

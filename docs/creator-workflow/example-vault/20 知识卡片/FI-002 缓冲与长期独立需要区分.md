# 缓冲与长期独立需要区分

短期承受收入中断与长期不依赖劳动收入是不同能力；每一步增加的自主性都有价值。

原创算术示例：30 万可用存款 ÷ 每月 1 万支出 = 30 个月；支出为 3 万则为 10 个月。假定无其他收入、忽略收益、通胀和意外支出，只用于说明时间尺度，不能用于决定辞职。

边界：流动性、债务、家庭责任和变化会影响可持续时间。

文章用途：案例和容错段。

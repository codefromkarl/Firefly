当前：未发布；B 站编辑器兼容性未实测。

## 人工交付动作

1. 通读主稿并核对研究账本，确认可以承担的观点；把人工确认记录写在本页。
2. 登记主稿版本，通过 creator:system preview 生成 B 站图文包，通过系统首页查看本次登记的当前交付指向。浏览器打开 bilibili.html，检查桌面和手机宽度；审查通过后用 release-prepare 固定最终标题、正文和图片，再由作者决定。
3. 在 B 站当前创作入口分别粘贴标题和正文富文本，按 asset-order.json 上传图片并移除占位。若格式丢失，使用 bilibili.txt，手动设置标题、段落、加粗和引用。
4. 检查所有来源网址是否仍保留并可打开；不支持超链接时以“来源标题 + 完整 URL”保留。人工核对版权、标题与正文承诺、图片来源、移动预览。
5. 保存草稿，记录平台预览结果和稿件日期；由作者执行发布，回填链接和发布时间。
